# ข้อมูลสถิติการเปิดรับนักศึกษาฝึกงานในประเทศไทย (Internship Statistics in Thailand)

เอกสารฉบับนี้รวบรวมข้อมูล Open Data สถิติ และรายงานตลาดแรงงานเกี่ยวกับการเปิดรับนักศึกษาฝึกงานในประเทศไทย โดยครอบคลุมจำแนกตามสายงาน รูปแบบการทำงาน เบี้ยเลี้ยง และทักษะที่ต้องการ

---

## 1. สรุปชุดข้อมูลสาธารณะและแหล่งอ้างอิง (Open Data & Public Reports)

| ชุดข้อมูล / รายงาน | หน่วยงาน / แพลตฟอร์ม | ประเภทข้อมูล | ลิงก์แหล่งที่มา / ดาวน์โหลด |
| :--- | :--- | :--- | :--- |
| **รายงานสถิติตลาดแรงงานและนักศึกษาฝึกงาน** | WorkVenture / JobDB by SEEK / GetLinks | รายงานสำรวจทักษะ เบี้ยเลี้ยง และอัตราการรับเข้าทำงาน | [WorkVenture Insights](https://www.workventure.com/blog) \| [JobDB Insights](https://th.jobsdb.com/) |
| **ฐานข้อมูลตำแหน่งงานและเด็กฝึกงาน** | CoopJobs / ThaiInternship / SuperResume | Open Data/สถิติตำแหน่งงานฝึกงานตามสายงาน | [CoopJobs Thailand](https://www.coopjobs.org/) \| [ThaiInternship](https://www.thaiinternship.com/) |
| **สถิติตลาดแรงงานและการจ้างงาน** | กรมการจัดหางาน กระทรวงแรงงาน | สถิติความต้องการแรงงานระดับแรกเข้า (Entry-Level/Intern) | [ระบบสารสนเทศตลาดแรงงาน (DOE)](https://smartjob.doe.go.th/) |

## 2. สรุปสถิติการเปิดรับนักศึกษาฝึกงานจำแนกตามสายงาน

ข้อมูลประมวลผลจากการสำรวจตำแหน่งเปิดรับฝึกงานย้อนหลัง (ตัวอย่างโครงสร้างข้อมูลอ้างอิงสัดส่วนจริงในตลาดแรงงานไทย):

| สายงาน (Department) | สัดส่วนการรับ (%) | จำนวนตำแหน่งเปิดรับ (ประมาณการ) | เบี้ยเลี้ยงเฉลี่ย (บาท/วัน) | รูปแบบการทำงานหลัก | ทักษะสำคัญที่ต้องการ (Top Skills) |
| :--- | :---: | :---: | :---: | :---: | :--- |
| **IT / Tech** | 28% | 1,400 | 350 - 600 | Hybrid / Remote | JavaScript, Python, Git, Problem Solving |
| **Marketing / Digital Content** | 22% | 1,100 | 300 - 450 | On-site / Hybrid | Social Media Analytics, SEO, Canva, Copywriting |
| **Data / AI** | 15% | 750 | 400 - 700 | Hybrid / Remote | SQL, Python/R, Power BI/Tableau, Machine Learning Basics |
| **Engineering** | 12% | 600 | 350 - 500 | On-site | AutoCAD, SolidWorks, Data Analysis, Safety Regulations |
| **Graphic Design / Creative** | 10% | 500 | 300 - 450 | Hybrid / Remote | Photoshop, Illustrator, Figma, Video Editing |
| **Finance / Accounting** | 8% | 400 | 300 - 500 | On-site / Hybrid | Excel (Advanced), Financial Analysis, ERP Basics |
| **HR / Talent Acquisition** | 5% | 250 | 300 - 400 | On-site / Hybrid | Communication, Screening Tools, Event Management |
